      A backtest is a hypothesis, not evidence. Validation re-tests the same strategy across many independent price samples, runs out-of-sample walk-forward folds, reshuffles the trade order (Monte Carlo), and doubles the spread to see whether the edge is real or just cheaper-than-the-spread noise. Note the data source: the offline simulator is calibrated to have no exploitable edge, so on synthetic data the honest answer is usually “rejected”.
